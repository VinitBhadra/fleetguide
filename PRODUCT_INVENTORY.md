## Quick Actions

### To Add New Product:
1. Find product on Amazon
2. Generate affiliate link
3. Download product image
4. Copy product template from AMAZON_AFFILIATE_GUIDE.md
5. Update index.ejs
6. Add image to /public/images/
7. Test locally
8. Deploy

### To Remove Product:
1. Delete product card HTML from index.ejs
2. Remove image from /public/images/
3. Update this inventory file
4. Deploy changes

### To Update Product:
1. Check current price on Amazon
2. Update price in HTML
3. Verify affiliate link still works
4. Update image if needed
5. Deploy changes
